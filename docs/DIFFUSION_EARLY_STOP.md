# 扩散优化的窗口早停与最大日程校准

本轮用户要求新增增量检测机制，并实际测试当前扩散方法的最大优化量。原默认流程和原图片保留；早停为可选扩展。

检测依据是项目实际第二检索代理对目标图像的余弦，不能用噪声潜变量或不同时间步的混合引导图像分数代替。每个检查点复制当前潜变量，执行剩余无引导确定性去噪到干净末态，再恢复原图尺寸、量化为八位图像后评分。检查不修改主优化轨迹、自适应模型权重或引导步数。

本次规则：第100个实际引导步建立基点，此前检查用于选优但不累计低收益耐心。此后每25步计算本窗口末历史最佳目标余弦减去上一窗口末历史最佳余弦。连续3个窗口增量小于0.002时停止，最早停止点为第175步。小幅刷新最佳值不会自动清空耐心，窗口总增量达到阈值才清空。阈值针对单个窗口，不代表所有窗口累计增长小于0.002。

候选包括零引导的重建基线。最终正常输出选择停止之前的历史最佳完整图片，并另外保存停止点完整图片，避免末步回退。每个检查点保存真实候选、评分、停止检查和进度记录。

完整扩散日程提高到本地调度器上限1000步；编辑强度保持此前0.5，故本次最多500个实际引导步。工作分辨率256、原图正则2、位移上限0.25、种子42等保持前次较强配置。1000步日程的起始时间点499与原60步日程起点464不同，不能把效果差异全部归因为更充分收敛。

本轮启用停止后校准：触发早停时冻结正常输出候选，随后继续同一条优化轨迹至500步，另存校准最优与最终图。这样可验证高噪声阶段的平台是否导致误停。此模式会继续消耗计算；日常使用关闭校准开关时才真正提前结束整次计算。完整校准的最佳结果仅表示这组参数与检查点中的最大分数，不能称全局最优。

配置：`src/configs/diffusion_group7_early_stop_max.json`。真实实验输出计划位于 `src/output/diffusion_group7_early_stop_max_20261011`，包含生成日志、图片、完整停止判断和校准分数；最终结果须由真实运行填写。

## 真实校准结果

实验已完成500个实际引导步。内部最佳检查点为第500步，目标余弦0.893926；最终统一重编码为0.893923。原规则175步触发，选中50步图0.741316，后续运行增加约0.152609，证实会误停。最后25步仍增加0.021485，不能称已经收敛。

这组100步基点／25步窗口／3次耐心／0.002阈值为已被实测发现会误停的研究配置，不建议直接当作可靠生产早停参数。默认关闭早停的行为保持不变；后续需要去噪阶段约束和多样本校准，单次平台不足以保证后续无收益。

500步图在未处理和有损压缩后的目标余弦分别为0.893923和0.802507，高斯半径4后为0.678507；视觉上有明显重影和文字变形，最大像素差255。整轮耗时85分31秒。完整整理见[本轮结果](../src/output/diffusion_group7_early_stop_max_20261011/RESULTS.md)。
